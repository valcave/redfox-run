# redfox.run

The website of Red Fox Run, Valerie Caveney's consultancy. One static page, no build step.

- `index.html` — the page
- `fonts/` — ET Book (woff2)
- `Red-Fox-Run-Valerie-Caveney.pdf` — the one-pager
- `Valerie-Caveney.vcf` — contact card
- `llms.txt`, `robots.txt`, `sitemap.xml` — for search engines and AI crawlers
- `vercel.json` — hosting config (clean URLs, caching, download headers)

Deployed on Vercel from the `main` branch.
